💡 What:
Removed the `@import` directive for Google Fonts from `src/index.css` and replaced it with `<link rel="preconnect">` and `<link rel="stylesheet">` tags directly in `index.html`.

🎯 Why:
Using `@import` inside a CSS file creates a serial request chain. The browser must first download and parse the entire CSS file before it discovers the `@import` statement and initiates the font download. This delays rendering. Moving the font declarations to `index.html` via `<link>` tags allows the browser to discover and download the fonts in parallel with the CSS and other assets, eliminating the bottleneck.

📊 Impact:
Significantly improves First Contentful Paint (FCP) by allowing parallel downloading of critical font assets alongside CSS, eliminating the CSS-blocking serial request chain.

🔬 Measurement:
1. Load the page and observe the Network tab in DevTools.
2. Note that the font stylesheet request (`fonts.googleapis.com/css2?...`) now starts in parallel with `index-[hash].css`, rather than waiting for the CSS request to finish.
3. Performance auditing tools (like Lighthouse) will no longer flag "Avoid chaining critical requests" for the fonts.
