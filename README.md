# ghostiemoh.com

Portfolio for **Muhammad Auwal Abdulaziz**, Data Analyst.
Live at [ghostiemoh.com](https://ghostiemoh.com).

Case studies where messy data becomes a clear finding and a recommendation,
in Excel, SQL, and Power BI, plus a second track in Solana on-chain analysis.
Every figure on the site traces to a workbook in [`public/projects`](public/projects)
or a linked repository.

## Featured case studies

| Case | What it shows |
| ---- | ------------- |
| [Call centre service-level analysis](https://github.com/Ghostiemoh/call-center-analysis) | 1,251 agent-day records. The line answers 92.7% of calls but only 70.9% inside its 20-second target, and the gap tracks call volume, not agents. |
| [Retail sales trend analysis](https://github.com/Ghostiemoh/retail-sales-dashboard) | 113,036 orders, 2011 to 2016. The apparent 2016 decline is a partial-year coverage gap, not a real downturn. |
| [Coffee retail growth analysis](https://github.com/Ghostiemoh/coffee-shop-sales-dashboard) | 149,116 transactions. Revenue doubled over six months while footfall stayed flat, so growth came from basket value. |

Also: the [DecodeLabs Global](https://github.com/Ghostiemoh/decodelabs-internship-project-1)
virtual internship (Python and SQL), a [Power BI inventory model](https://github.com/Ghostiemoh/apocalypse-food-prep-power-bi),
SQL exploration and cleaning scripts, and [on-chain investigations](https://github.com/Ghostiemoh/Blockchain-Analysis).

## Stack

React 18 and Vite, deployed to GitHub Pages from `main`. Tailwind is used only
for its preflight reset; the visual system is hand-authored CSS in
`src/index.css`. Charts are inline SVG. No analytics, no trackers.

```bash
npm install
npm run dev
npm run build
npm test
```

See [`AGENTS.md`](AGENTS.md) for architecture notes and the content-accuracy
rules, and [`brand.md`](brand.md) for the design system.
