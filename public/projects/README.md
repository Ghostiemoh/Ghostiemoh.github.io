# Project files (Excel, PDF, etc.)

Drop your `.xlsx` project files in this folder. Anything here is served at
`/projects/<filename>` on the live site and opens/downloads when its card is clicked.

Example: `public/projects/sales-dashboard.xlsx`  →  link `/projects/sales-dashboard.xlsx`

Tip: use simple lowercase filenames with hyphens (no spaces) so the links are clean.
