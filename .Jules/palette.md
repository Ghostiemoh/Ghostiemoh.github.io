# Palette's Journal

## 2025-05-15 - Missing Skip-to-Content Link
**Learning:** This portfolio site lacks a "Skip to content" link, a fundamental accessibility feature for keyboard users to bypass navigation.
**Action:** Always check for bypass blocks in single-page applications or pages with heavy navigation headers.

## 2025-05-20 - Long Scroll Navigation Gaps
**Learning:** Users can easily lose context on long single-page sites, especially on mobile. Without persistent navigation, scrolling back up becomes a friction point.
**Action:** Add "Back to Top" buttons or persistent navigation aids for pages longer than 2 viewports.
