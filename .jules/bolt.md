## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2025-03-02 - Framer Motion v11+ Optimization
**Learning:** In this project, Framer Motion v11+ is used, allowing you to directly pass `MotionValue`s (e.g., from `useTransform`) as children to `<motion.*>` components. This is the preferred implementation for bypassing React re-renders for continuous values. Critically, the `MotionValue` must be the *single, direct child* of the motion element (e.g., `<motion.span>{displayPercent}</motion.span>`). Mixing it with other text or elements (like `<motion.span>{displayPercent}%</motion.span>`) causes a fatal React crash. Format strings inside `useTransform` instead.
**Action:** Always map continuous values via `useTransform` into formatted strings and pass the returned `MotionValue` directly as the sole child of a `<motion.*>` element.
