## 2025-04-08 - Contact Form Submission Memory Leak & Cold Path DOM Caching
**Learning:** Adding an `addEventListener` inside a recurring asynchronous UI flow callback (like a form submission's email client fallback timeout) can lead to a memory leak and performance degradation if the listener captures closure variables (like `subject` and `body`) that change on each execution. Additionally, while optimizing cold paths like form submissions yields small improvements, standardizing on DOM element caching outside these functions is a required best practice for this codebase.
**Action:** When implementing asynchronous UI fallbacks or repeatable actions that bind event listeners capturing local scope variables, prefer overwriting existing handlers with `.onclick` (or similar direct assignments) instead of `addEventListener` to prevent duplicate binding. Always cache required DOM elements at the script scope rather than querying them inside the handler, even in non-critical paths.
