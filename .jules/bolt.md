## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Bypass React Re-renders for Continuous Animations
**Learning:** Using `setInterval` with React's `useState` for continuous, rapidly updating animations (like counting numbers) forces the component to re-render repeatedly (e.g., every 16ms), which creates significant overhead, triggers unnecessary garbage collection, and blocks the main thread.
**Action:** When using Framer Motion, prefer using `useMotionValue` combined with `useTransform` and `animate` for continuous values. This allows Framer Motion to directly update the DOM, completely bypassing the React render cycle and dramatically improving performance. Note that the `MotionValue` must be the *single, direct child* of the motion component (e.g., `<motion.span>{motionValue}</motion.span>`) to avoid React string interpolation crashes.
