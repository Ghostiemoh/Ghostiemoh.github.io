## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Bypass React render cycle for Scroll Progress
**Learning:** Using `useState` and `useEffect` to capture continuous updates (like `scrollYProgress.onChange`) triggers a full React component render cycle on every update (e.g., every scroll frame). For values that are only used visually and do not dictate React logic, this causes unnecessary main-thread blocking and layout recalculations.
**Action:** When working with Framer Motion, use `useTransform` to derive a new `MotionValue` and pass that value directly to a `<motion.*>` element as a child (e.g., `<motion.span>{displayPercent}</motion.span>`). Framer Motion will update the DOM node directly, completely bypassing the React render cycle and improving visual performance during scrolling.
