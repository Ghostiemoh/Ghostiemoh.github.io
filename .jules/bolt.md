## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Bypass React Re-renders with useTransform and MotionValues
**Learning:** In Framer Motion v11+, a common performance anti-pattern is using `useEffect` with `scrollYProgress.onChange()` to update React state (e.g., `useState`). This forces the entire component tree to re-render constantly during scrolling. A better approach is using `useTransform` to convert `scrollYProgress` to the desired format and passing that `MotionValue` as the direct, solitary child of a `<motion.*>` component.
**Action:** Replace `useState` and `onChange` hooks bound to scroll values with `useTransform` formatted strings, and pass the resulting `MotionValue` as the single child to `<motion.*>`. Ensure the MotionValue is the absolute solitary child (do not concatenate strings in the JSX like `{value}%`) to avoid crashes.
