## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Extract Static Data and Memoize Derivations
**Learning:** React functional components re-declare arrays and re-evaluate mapping/filtering logic entirely on every render. If these structures are heavy or derived logic iterates N elements, it leads to O(N) recalculations and re-allocations on every single render cycle, creating a performance bottleneck, especially under animation layers or scroll events that might trigger frequent updates.
**Action:** Always move purely static arrays/data out of the React render function completely. When derived state is computed from arrays (like filtering items by a selected category), wrap the derivation in `React.useMemo` to skip recalculation unless the dependencies change.
