## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Avoid React state for Framer Motion scroll progress tracking
**Learning:** Using React state (e.g., `setDisplayPercent`) to track Framer Motion continuous scroll values (like `scrollYProgress`) causes the component to re-render on every frame while scrolling. This defeats the performance benefits of Framer Motion, which is designed to handle animations outside of the React render cycle.
**Action:** Use `useTransform` to map scroll values and render them directly using `<motion.span>{transformedValue}</motion.span>`. For displaying text/numbers, Framer Motion provides `useMotionTemplate` and `useSpring` to keep the UI up-to-date without triggering re-renders.
