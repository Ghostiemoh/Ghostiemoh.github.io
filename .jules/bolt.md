## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-11-20 - Optimizing Frequent Animations with Framer Motion
**Learning:** Using React state (e.g., `useState`) inside a rapid interval (like a 16ms `setInterval` for a counter animation) forces a full React render cycle and DOM commit on every tick. For a 2-second animation, this can cause over 120 unnecessary React re-renders, blocking the main thread.
**Action:** When animating continuous numerical values in Framer Motion, bypass React state entirely by using `useMotionValue` and the `animate` function. The resulting `MotionValue` must be passed as the sole, direct child to a `<motion.*>` element (e.g., `<motion.span>{displayValue}</motion.span>`). This allows Framer Motion to update the DOM directly, saving significant CPU cycles.
