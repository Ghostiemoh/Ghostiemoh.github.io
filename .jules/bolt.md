## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-05-24 - Extracting Static Arrays in React Components
**Learning:** Defining large static arrays (like list data or navigation configurations) directly inside a React component's render function forces the Javascript engine to re-allocate memory and re-create the entire array on every single render cycle. While often functionally harmless, this creates unnecessary garbage collection overhead and can slow down rendering, particularly for components that re-render frequently (e.g., due to scroll events or animations).
**Action:** Always extract arrays that contain purely static data (including JSX elements referencing globally imported components) outside of the React component to the module level. This ensures the array is only allocated once when the module is evaluated, reducing execution time for data access by approximately 11x in tight loops.
