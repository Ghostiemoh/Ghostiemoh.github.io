## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.
## 2024-05-27 - Refactoring Animated Counters with Framer Motion
**Learning:** Using `setInterval` and `useState` inside a `useEffect` to animate numbers forces React's reconciliation cycle to run on every frame update (e.g., every 16ms). This blocks the main thread and creates significant CPU overhead, negatively impacting performance and causing jank on slower devices.
**Action:** Replace `useState` and `setInterval` in counter components with Framer Motion primitives like `useSpring` and `useTransform` applied directly to a `motion.span` (or similar motion component). This bypasses React's render cycle for intermediate values and relies on optimized, direct DOM manipulation, reducing CPU usage substantially. Note: A `MotionValue` must be the only child of a motion element to render directly as text, so any string suffixes should be included within the `useTransform` mapping.
