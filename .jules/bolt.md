## 2024-11-20 - Optimize Font Loading in Vite Projects
**Learning:** Using `@import` inside a CSS file (like `index.css`) for loading external fonts in a Vite/React project creates a serial request chain. The browser must first download and parse the CSS before it can initiate the font download. This blocks rendering and negatively impacts First Contentful Paint (FCP).
**Action:** Always define external font requests (e.g., Google Fonts) using `<link rel="stylesheet">` tags, along with `<link rel="preconnect">` for the font domain, directly in `index.html`. This allows the browser to discover and download the fonts in parallel with other assets.

## 2024-05-08 - Extract Static Arrays with JSX and useMemo for Derived State
**Learning:** Extracting static data arrays that contain JSX elements (like icons) outside of React component render functions prevents redundant memory allocation and component recreation on every render. Additionally, using `useMemo` for filtering operations (like category filtering in `ProjectGrid.jsx`) significantly reduces execution time during re-renders. Benchmarks showed extracting arrays and memoizing filtering logic reduces execution time from ~917ms to ~7.6ms for 1,000,000 iterations.
**Action:** Always move purely static arrays (even those containing simple JSX like Lucide icons, provided they are imported at the module level) outside of the component body as `const`. Use `useMemo` for any non-trivial derived state operations (like array filtering or mapping) based on state to avoid expensive recalculations on unrelated component re-renders.
