## 2025-02-28 - Optimize font loading for FCP\n**Learning:** In Vite/React projects, defining external font requests (e.g., Google Fonts) using `<link>` tags with `preconnect` attributes directly in `index.html` instead of using `@import` inside CSS files like `index.css` optimizes First Contentful Paint (FCP) and avoids serial request chains.\n**Action:** Apply this optimization pattern proactively when encountering external font loading via `@import` in CSS.
